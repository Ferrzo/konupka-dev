# konupka.dev

Personal portfolio website built with Astro, showcasing my work as a frontend developer.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build) - Modern static site builder
- **Deployment**: [Netlify](https://www.netlify.com/)
- **Language**: TypeScript
- **Styling**: CSS

## ✨ Features

- Responsive design
- Dark/Light theme support
- Portfolio showcase
- Blog section
- Optimized performance with Astro
- SEO-friendly with sitemap generation


## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```sh
git clone https://github.com/Ferrzo/konupka-dev.git
cd konupka-dev
```

2. Install dependencies:
```sh
npm install
```

3. Start the development server:
```sh
npm run dev
```

The site will be available at `http://localhost:4321`

## 🧞 Commands

All commands are run from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
